# 📸 Screenshot Assistant

Never miss an important screenshot again.

---

## 🇺🇸 English

Screenshot Assistant is a client-side Fabric mod that automatically captures screenshots whenever a chat message matches one of your rules.

I originally created this mod for the **GunMax** server because I kept forgetting to press **F2** after getting a kill for weekly gang job reports. Instead of searching through chat history later, the mod captures the moment automatically.

Although it started as a GunMax utility, my goal is to turn it into a flexible screenshot automation mod that can be useful on any Minecraft server.

---

## Features

- 📷 Automatic screenshots triggered by chat messages
- 📝 Unlimited custom rules
- 🔍 AND / OR keyword matching
- 📍 Match keywords anywhere, first word, last word or at a specific position
- 👤 Optional player filter
- 🚫 Ignores old chat history (only new incoming messages)
- 🔢 Automatic sequential filenames (`1.png`, `2.png`, ...)
- 📁 Optional weekly folder rotation
- 📅 Gregorian and Jalali calendar support
- ⏱ Configurable anti-spam cooldown
- ⚙️ In-game configuration screen
- 💡 Helpful tooltips for every setting

# Installation

1. Install Fabric Loader for Minecraft **1.21+**
2. Install Fabric API
3. Install Cloth Config API *(required)*
4. *(Optional)* Install Mod Menu
5. Place the mod inside your `.minecraft/mods` folder.

---

# How to use

- Press **F6** *(rebindable)* to open the configuration screen.
- If Mod Menu is installed, you can also open the settings from the Mods menu.

Create a rule by:

1. Opening **Manage Rules**
2. Clicking **Add Rule**
3. Choosing your keywords
4. Selecting **AND** or **OR**
5. Saving the rule

That's it — the mod will automatically capture screenshots whenever a matching chat message appears.

# Privacy

Screenshot Assistant runs entirely on your computer.

It does **NOT**:

- connect to the internet
- upload screenshots
- collect personal information
- send any data to servers
- execute external programs

Everything happens locally.
